# Model Library — Complete Reference

## Market & Business Strategy Layer

**Core Question**: Not what the product looks like, but what environment the competitor operates in, who they sell to, and what keeps them alive.

| Model | Purpose | Best Used When |
|-------|---------|---------------|
| **PESTEL** | Macro-environment analysis (Political / Economic / Social / Technological / Environmental / Legal) | Scanning the environment before entering a new market |
| **Porter's Five Forces** | Industry and competitive landscape analysis | Assessing industry attractiveness and entry barriers |
| **Porter's Competitive Strategy** | Defining overall direction (Cost Leadership / Differentiation / Focus) | Identifying a competitor's overarching strategic posture |
| **Porter's Strategy Wheel** | Ensuring all business activities are tightly aligned with the core strategy | Auditing strategic consistency |
| **Ansoff Growth Matrix** | Mapping business growth paths (Market Penetration / Market Development / Product Development / Diversification) | Analyzing a competitor's expansion logic |
| **VRIO Analysis** | Evaluating internal resource competitiveness (Value / Rarity / Imitability / Organization) | Assessing the depth of a competitor's moat |
| **Value Curve (Blue Ocean Strategy)** | Identifying differentiated value space beyond existing competition | Spotting differentiation opportunities |
| **RIIF Strategic Model** | Strategy building across Resources / Information / Influence / Finance dimensions | Comprehensive strategic resource assessment |
| **Industry Life Cycle** | Judging evolutionary trends in economic and management dynamics | Determining the stage a given industry is in |
| **Gartner Hype Cycle** | Tracking public expectation trends for emerging technologies | Timing decisions for technology-driven products |
| **SWOT Analysis** |综合 situational overview and market positioning | Quick full-picture scan |
| **Business Model Canvas (BMC)** | Mapping the nine core modules of how value is created, delivered, and captured | Systematic business model deconstruction |
| **Marketing Mix (4Ps / 7Ps)** | Defining the go-to-market strategy | Analyzing a product's launch and commercialization strategy |
| **Perceptual Mapping** | Visualizing how consumers mentally position different brands and products | Brand positioning comparison |
| **Benchmarking** | Measuring against industry best practices to identify strategic gaps | Finding areas for improvement |

## Product & Business Architecture Layer

**Core Question**: What solutions has the product built in order to achieve its commercial goals?

| Model | Purpose | Best Used When |
|-------|---------|---------------|
| **BCG Matrix** | Product strategy and prioritization | Analyzing resource allocation across a multi-product portfolio |
| **KANO Model** | Layering product features by value type (Basic / Performance / Excitement / Indifferent / Reverse) | Assessing the value tier of specific features |
| **Stakeholder Analysis** | Mapping interests, power dynamics, and win-win opportunities across ecosystem actors | Analyzing platform-type products |
| **vALUe** | Value-driven innovation and evaluation framework | Evaluating innovation opportunities |
| **MECE** | Breaking complex business challenges into mutually exclusive, collectively exhaustive sub-problems | Structuring a problem space |
| **Stage-Gate Model** | Risk control across product development phases | Evaluating product development stage-readiness |
| **Harris Profile** | Multi-dimensional visual comparison of concept strengths and weaknesses | Side-by-side comparison of multiple solutions |
| **EVR Decision Matrix** | Decision matrix across Experience / Value / Risk dimensions | Evaluating feature or product decisions |
| **PMI (Plus, Minus, Interesting)** | Fast assessment of a concept's pros, cons, and interesting implications | Quick concept review |
| **CBox (Creativity Box)** | Cross-evaluating novelty vs. feasibility | Filtering innovative concepts |
| **Objective Weighting** | Assigning weights to multiple business goals to resolve resource conflicts | Prioritization under constraints |
| **Ansoff Matrix** | Product growth and expansion paths | Analyzing product line expansion |
| **System Map** | Visualizing relationships between components and roles in a product ecosystem | Ecosystem-level analysis |
| **Service Blueprint** | Defining the end-to-end service journey and internal collaboration lines, connecting front-stage experience with back-stage support | Service process analysis |

## UX & Execution Layer

**Core Question**: What does the user actually see, click, and feel on screen? The emphasis is on getting the details right.

| Model | Purpose | Best Used When |
|-------|---------|---------------|
| **Fogg Behavior Model (B=MAP)** | Motivation (M) + Ability (A) + Prompt (P) → behavior conversion | Analyzing conversion rates and user activation |
| **User Journey** | Connecting micro-touchpoints to reveal emotional and behavioral patterns across a task | Full end-to-end experience analysis |
| **How Might We (HMW)** | Reframing pain points as specific design challenges and divergence prompts | Identifying design opportunities |
| **Card Sorting** | Validating whether information taxonomy matches users' actual mental models | Information architecture evaluation |
| **Gutenberg Diagram & Z/F-Pattern Reading Flow** | Analyzing whether layout aligns with natural eye-scanning patterns | Interface layout analysis |
| **Focus Flow Assessment** | Evaluating how visual attention, interaction control, and task context are intuitively handed off | Interaction flow evaluation |
| **Hick's Law** | Analyzing whether the number of choices increases user decision time | Choice and option design evaluation |
| **Fitts's Law** | Evaluating tap target size and distance to assess interaction efficiency | Touchscreen and click-target design |
| **Critical Path Analysis** | Decomposing the core conversion path, analyzing drop-off probability and interaction friction at each step | Conversion funnel analysis |
| **Atomic Design** | Systematic deconstruction of interface building blocks, including: typography, color systems, spatial planning and grid, visual assets, Design Tokens mapping, component library scalability, design principle consistency, visual metaphor evaluation | Deep design system analysis |
