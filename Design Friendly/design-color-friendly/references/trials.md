# 色彩友好化试用案例

在需要理解匹配边界或复核规则时读取。案例中的色值与名称来自当时使用的规范，换档后以本轮 JSON 为准。

| 观察 | 判断与处理 | 验收 |
| --- | --- | --- |
| 商品卡的底色和「抢」按钮文字都是 `#FFFFFF`、`100%` | 卡片底色匹配 `灰阶/gray_1`。反白文字按文字用途核对并独立维护 | 两处各自绑定，按用途可独立修改 |
| 商品标题、服务标签文字和次要信息原色都未精确命中 | 校准时按用途采用一级文字色、服务金文字色和三级文字色。只做变量化时可记录为待校准 | 复查各文字的颜色绑定、字体和位置 |
| 抢购按钮的橙色填充下有一层已启用的亮黄 | 先关闭亮黄验证，再移除无效填充。左侧原稿仍使用对应变量，因此保留变量 | 关闭前后与移除后的截图逐像素一致 |
| 权益卡副标题的说明文字与金额分色，浅粉领取按钮底色无规范对应项 | 说明文字和金额分别匹配次要文字色和品牌主色。三处同用途的浅粉底色共用一个本地例外变量 | 富文本区间、按钮实例关系及可见呈现均已核对 |

记录新案例时写明规范来源及版本、目标状态、实际观察、处理依据、验收结果和用户反馈。案例有可回查来源时保留定位信息。仅个别稿件适用的选择留在案例里。出现可复现的通用缺口时，修改对应规则并用相关既有案例复核。
