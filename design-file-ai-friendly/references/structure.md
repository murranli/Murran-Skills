# 结构清理

仅处理层级与命名。纯改名无需规范库；需要判断功能层级时读取 [layers.json](specs/JD-16.0/layers.json)。

- 仅删除、拍平或合并确认没有独立视觉、布局、交互、导出、资产作用的冗余结构。拟修改时才检查相关约束。
- 隐藏、透明、可视区外、空容器或单子级都不直接代表无效。空容器可能承载背景/效果；图标透明背景可能承担导出边界。
- 删除重复层先检查透明度、混合与效果叠加；拍平或迁移先检查裁剪、留白、坐标变换、层叠及语义作用。保持必要属性不变属于结构操作的等效迁移，不允许顺带调间距或改视觉。
- 仅按明确归属整理孤岛图层，按实际作用选择Frame或Group；不强制转换容器，不解除组件关系。无法确认归属则保留。
- 保留语义清晰的名称，只修正默认名、误导名及明显不一致名称。业务明确时使用业务名称；同型阵列可用“商卡01、商卡02”，不确定时用类型加编号。不改组件接口或变体属性名。

必要保护检查可识别组件、实例、蒙版和导出设置；资产候选检索仅在资产匹配模式启用时进行。
