# 布局调优

读取 [layout.json](specs/JD-16.0/layout.json) 及未决问题。位置、尺寸、间距、内边距和自动布局归本模式，对应变量绑定也归本模式。

- 对意图明确的误差，在已给容差内对齐。稳定排列且有维护价值时可补自动布局，须保持当前视觉及原有尺寸策略、换行、裁剪与伸缩行为；不能可靠保持则保留原布局。
- 保留有意错位、叠放、绝对定位；不强制处理独立ICON、插画或运营素材，不为符合栅格统一调整所有数值。
- 约150%行高对应的纵向间距换算仅用于规范明确的迁移条件，不是全稿减8规则，不重复执行已完成换算。单位、适配宽度及页面类型须先确认。
- 需要改文字属性时，先读取 [typography.json](specs/JD-16.0/typography.json) 的行高冲突；未启用样式模式则只提建议，不自行改行高。单纯核验现有行高不算启用样式修改。
- 只新增实现本模块布局所必需的容器；不顺带清理无关层级或命名。布局涉及叠放语义时再读 [layers.json](specs/JD-16.0/layers.json)。
