# 样式修正

按实际涉及属性读取 [色彩](specs/JD-16.0/colors.json)、[文字](specs/JD-16.0/typography.json)、[圆角](specs/JD-16.0/radius.json) 或 [材质](specs/JD-16.0/materials.json)，包含对应未决问题。不读取全部主题。

- 区分文字样式和变量；文字样式按其实际影响核对字体、字号、字重、行高、字间距、段落等字段，混合文本逐段保留局部格式。颜色同时核对用途、模式、填充/图层透明度；效果核对全部效果层与顺序。
- 仅将语义适用、全部受影响属性完全一致的现有资源直接绑定。规范未提供完整属性或引用时不声称可绑定；绑定流程见 [standards.md](standards.md)。
- 颜色、文字、圆角或效果的可见修正仍需明确依据与容差；来源冲突或条件未覆盖时保留并记录。近似颜色仅在本批匹配中遇到时记录，不另作全稿穷举检索。
- 优先复用变量。只有用户已授权相应属性整理、重复维护确有需要且值/语义明确时，才新增本稿专用的本地变量，并仅绑定副本；不以新变量冒充官方资源，不覆盖既有变量。
- 本模式不修改坐标、尺寸、间距、内边距或自动布局。字号/行高变化后检查换行和裁剪；若需布局补偿而未启用布局模式，撤回该项并给出建议。
