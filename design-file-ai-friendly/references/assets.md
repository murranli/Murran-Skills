# 资产匹配

仅收集用户选区内的素材、ICON/LOGO、基础及业务组件；已有组件、实例、蒙版保留关系。去重后查询相关候选，不另扫整文件，不创建组件、不导出切图。

涉及图标时读取 [icons.json](specs/JD-16.0/icons.json) 及未决问题；其他组件先检查 [存档覆盖](specs/JD-16.0/INDEX.md)。示例节点、文本出处ID及本地检索键均不可充当资产引用。

按用途、结构、尺寸、状态/变体、模式及内容保留能力，区分“完全匹配或对应变体 / 仅相关 / 无匹配”。不能只凭名称或外观判定等同。库查询与详情获取见 [standards.md](standards.md)。

先集中展示可执行候选：当前节点及位置 → 目标组件/变体、真实资源引用、匹配依据、预计变化、内容及局部样式保留情况。仅相关项作为建议；缺完整详情或无法保留内容的候选不进入替换批次。

“执行资产匹配”只授权查询。具体替换/变体关联经用户确认后，才在副本执行并验收。若原选区已有本任务副本则复用；已有明确确认覆盖同一候选时直接继续。目标或预计影响变化后重新确认该差异。待确认期间继续其他独立操作。
