# 设计稿件 AI 友好化

保持内容、视觉和既有功能，提升设计稿的结构清晰度与可维护性。先确定操作范围，再按需读取规则。

## 选择操作

| 用户表达 | 执行范围 | 需要时读取 |
| --- | --- | --- |
| 结构清理、清理层级、整理图层、规范命名 | 层级与命名 | [structure.md](references/structure.md) |
| 样式修正、样式对齐、绑定文字或颜色规范 | 文字、颜色、圆角、效果及对应绑定 | [styles.md](references/styles.md) |
| 布局调优、布局优化、整理间距、补自动布局 | 位置、尺寸、间距、内边距、布局及对应绑定 | [layout.md](references/layout.md) |
| 资产匹配、匹配组件、匹配图标 | 查找候选；确认后替换或关联 | [assets.md](references/assets.md) |
| 更新规范、学习新版规范，并提供链接 | 刷新指定规范存档 | [standards.md](references/standards.md) |

单项只启用该项，组合取并集；“全部四项”启用四项。“全局”仅指用户选区及其全部后代，不扩大到页面或文件，也不自动开启其他操作。未指定模式且上下文不能确定时，简短询问需要哪几项；等待时只做必要的只读定位。

“继续”沿用已记录的选区、模式与副本；不因当前选择变化重新选稿。用户明确改变范围或模式时更新任务记录。保护性读取和副作用检查始终执行，但不授权跨模式修改。

## 共同约束

- 所有设计修改只落在选区副本。保护文案、图片、局部格式、组件及交互关系；不改原稿、选区外节点、源组件或既有共享变量、组件库。
- 样式/变量须用途适用且全部受影响属性完全匹配。数值相同不代表用途相同。近似色只记录候选，不自动替换。
- 改变画面的数值或对齐修正须有明确依据，并落在用户或规范明确给出的容差内。无容差只给建议；不因参考宽度为375强制整数化，不插值补齐规范空白。
- 组件替换/变体关联先展示具体候选，再经确认执行。对已确认且目标与影响未变的同一批候选，续跑不重复询问。
- 不确定的节点保留。缺规范、库或工具能力只阻塞依赖项；同类问题合并记录，不反复重试，不标为完成。

## 执行

1. **定位一次。** 获取用户选中的根节点，去除祖先与后代重复选择，记录文件、页面、原节点和启用模式。无明确选区时请用户选择。只读取本次所需属性；使用当前设计软件的官方工具，调用脚本前加载它要求的技能/API文档。
2. **写入前建立副本。** 保存基准，在原稿右侧空余位置创建可编辑副本，保留原节点到副本的映射。跨轮复用同一副本。仅资产查询先只读，确认替换后才创建副本。不能可靠创建或撤回时不开始写入。
3. **按模块处理。** 以可独立验收与回退的模块分批；读取一次，执行已启用且适用的操作。结构变更自子容器向父容器；依赖已改变时只重读受影响部分，不为每个模式重扫全稿。
4. **按需查规范。** 遇到规范判断或绑定才读 [standards.md](references/standards.md)，随后只取相关主题及其未决问题。组合模式共享规范、属性签名和候选查询缓存；对象、相关属性、用途、模式或资源版本变化时仅失效对应缓存。
5. **批末验收。** 仅改名或完全等效变量绑定时做属性核验。结构、布局、文字样式等可能影响渲染时，对本批原稿基准做同范围、比例、背景的视觉比较，排除副本放置偏移。仅核验实际影响的内容、换行、裁剪、层叠、位置，以及相关组件、滚动、交互和导出行为。

非预期变化撤回本批，记录原因并继续独立模块；需要跨模式补偿才能成立的改动，也先撤回并列为建议。无法可靠撤回时停止写入，报告受影响范围与状态。未验证项保持待验证。

## 时限、续跑与反馈

每轮处理小于30秒，包含本批读取、修改、验收和反馈。启动时计时，根据已观察到的工具耗时缩小批次并预留验收时间；接近上限不启动新写入。不可中断的调用超时则如实记录，结束后先核验实际状态，缩小后续批次；不得省略验收或盲目重放写入来满足时限。

在任务可写工作区持久保存最小续跑记录：原选区、启用模式、副本映射、基准位置、规范版本、已验证/待验证/待处理模块、待确认候选及已确认范围。没有持久存储能力时，在反馈中保留这些继续所需信息。恢复时先核验下一批与已知变化，不重扫未变化的完成模块。

每批反馈只列有内容的项：完成范围与验收结果、重要跳过或未验证项、待确认项、继续位置。无需用户输入时自动继续后续批次。全部模块完成且存在视觉修改时做一次整稿对比；与末批范围相同时复用结果。最终区分已完成、待确认、跳过和未验证；近似色按“位置 / 原色 / 候选规范色 / 未修改”列出。
