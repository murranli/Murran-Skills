# 输出模板 Output Template

默认 **Markdown 可预览文档**。以下结构源自真实迭代（济州岛案例，经用户手动优化）。按需增删块，但**顺序遵循"最影响决策的先说"**。

---

## 结构骨架

```markdown
# <目的地><主题>：<一句话定位>
> 一句话主题 + 关键前提（谁去、几天、什么调性）

## ⚠️ 关键提醒 / 生死线（若有）
把"错了会导致行程崩盘"的点放最前：签证隐藏条件、旺季售罄、末班车、天气窗口。
每条 1–2 句，带原因。

## 出行时间
<方案A / 方案B 对比>：日期、请假安排、各自优劣（价格/天气/从容度）。
给推荐项并说明理由。

## 往返交通
> 标注"价格区间以 X 参考"、时区换算说明
按取向分组（便宜 / 舒适 / 组合），每组一张表：
| 往返 | 航班号（航司） | 起降时间 | 价格区间 |
交易级信息（航班号）→ 必须可核实措辞；价格标"+"或区间，注明以实时为准。
附订票平台建议 + 订票策略一句话。

## 行程计划
> 需含每日天气预估、起终点、中间行程耗时、就餐推荐
### DAY1 <一句话总结>
| 预估时段 | 行程安排 | 备注 |
|---|---|---|
| 上午 | 🛬 落地→前往<住地> | 交通耗时/方式 |
|  | 🥣 早/午饭 |  |
| 15:00- | 🏨 入住 | 入住/退房时间 |
|  | 🌊/🌳 <核心活动：起点→终点> | 距离/时长/难度/遮阳 |
|  | 🥣 晚饭 eq：<推荐> |  |
### DAY2 …（同上）
（emoji 图例：🛬抵达 🛫返程 🏨住宿 🥣餐 🌳徒步 🌊海岸 🎨室内/艺术 🚌交通 😴休息 🌀天气）
< 备选/加量路线 >

## 住宿备选
按档位分。青旅可单列；民宿/酒店在行程/人数未定时，可合并为"民宿OR酒店，人均¥X，行程定后再挑"+平台建议，不硬凑具体房源。
| 名称 | 位置 | 价格(每人/晚) | 备注 | 推荐预定平台 |
选址策略一句话（住哪最省交通）。

## 必要装备（若为徒步/户外等）
分"必备 / 建议"两级，勾选清单式。结合季节痛点（防晒/防雨/防磨脚）。

## 实用信息
- 目的地小知识（导航、门票文化、App）
- 入境 & 货币（签证、汇率、交通卡）
- 🌀 天气/极端天气备选预案（plan B 的具体去处）

## 人均预算（可选）
| 档位 | 住+餐/天 | ×N天 | +交通 | 人均合计 |

---
*信息来源：<逐项列>。价格与政策具时效性，交易级信息请以出行前官网/平台实时为准。*
```

## 输出后必做
- 明确指出**哪些是 C 类、需用户自己核实**（航班号、房源、实时价）。
- 提可继续细化的方向（如"定了人数我可精算人均"）。
- 若用户要 HTML：用信息可视化式排版（配色系统、明暗自适应、响应式、可打印），但内容分级纪律不变。
