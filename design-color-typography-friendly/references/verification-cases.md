# 联合处理的边界与复核案例

需要复盘、检查规则覆盖或为新案例修订本包时读取。历史稿件支持下述判断边界；联合编排的实际耗时仍需在真实任务中测量，不由案例推定加速比例。规范数值始终以本轮 JSON 为准。

## 继承的判断边界

| 场景 | 联合处理时的判断 | 应保留的证据或边界 |
| --- | --- | --- |
| 价格富文本的说明与金额分色，符号、整数和小数又使用不同格式 | 共读所有相关属性，按区间边界并集判断色彩和文字角色；分别应用各属性的目标 | 金额色与金额排版各自有依据，修改颜色不清空字号，修改字体不覆盖区间填充或绑定 |
| 卡片底色和反白文字同为白色 | 依据用途分别匹配和维护，而非以 HEX 去重为一个语义变量 | 两个维度可共用节点定位，但不能用文字层级代替颜色用途 |
| 商品标题、服务信息、次要说明原色未命中规范 | 校准按用途匹配；仅变量化保留现值并记录待校准 | 没有未覆盖证据时不直接创建 `Unm.`；字号是否合规独立判断 |
| 不透明橙色填充下有一层亮黄，面板中两者均启用 | 保持其他属性不变，先关闭亮黄比较，再在证据覆盖且获授权时清理 | 不能在同时换色、换字体的截图中证明该填充无效；变量是否删除另查全文件引用 |
| 连续说明与金额因前段 FILL 被拉开 | 前段按自然内容宽度衔接，余量在整句与外部图标之间分配 | 保留颜色及字体区间、单行预算和图标几何；同稿全部入口均需查找 |
| 主标题自然宽等于现有固定宽，或左对齐末段 FILL 只在句尾留空 | 保留稳定边界和必要截断 | 不能为统一模式全部改为 HUG，句尾空白不等同于句内缝隙 |
| 金额符号视觉下坠，或原单行门槛说明被预留了两行 | 以主数字基线校准符号，恢复有依据的原行数预算 | 允许值与偏好分开；不能因一个场景给所有字号升级、所有说明加行 |
| 文字重排后优惠券缺口变成椭圆或横缝 | 检查文字容器是否驱动了布尔内部缩放，保留正常构造几何 | 布尔外框可大于可见宽；不能压缩构造边界来匹配卡宽 |

## 联合编排的重点复核

- **换档**：只替换颜色或文字 JSON、甚至沿用同一路径时，受影响索引和匹配确实更新。同一稿件、状态、执行模式及相关属性均未变化且原检查仍有效时，另一维可复用结果；新目标或发生变化的区域不能因规范未更新而跳过检查。文字重排影响色彩覆盖关系时仍需联动补查。
- **分段**：颜色边界与字体边界不同的富文本，修改后所有未授权变化的区间和绑定仍保留；相邻写入区间的合并只作用于指定属性。
- **缓存**：结构重组、更改内容、样式覆盖或切换模式之后，节点身份、区间范围、测量及绑定信息按影响失效。清单不得继续写向已被替换的节点或旧画笔数组。
- **授权与缺口**：仅变量化不改颜色；未授权清理不删除填充。某一维缺少规范或资源时，独立可确定的另一维继续，共享结构有风险的局部保持待核实。
- **共用验收**：同一轮恢复后的截图与属性检查能验证两维目标；清理等操作仍有可归因的单独证据。布局可能改变覆盖关系时，候选填充保留至布局稳定；已经移除而需复核的，先恢复再比较。金额、截断、组件状态和非文字造型的必要局部检查不能因共享验收而跳过。
- **效率**：比较同一范围、来源和任务模式下的实际调用与耗时，观察是否减少重复全稿扫描、重复副本、无效写入和重复测试。分批和局部读回只要有依赖依据，就不视为冗余。

新案例只补充已观察到的缺口，记录规范身份、目标状态、变化、处理依据、验收及用户反馈。修改本包后复核受影响的既有边界，独立色彩与文字 skill 保持原样。
