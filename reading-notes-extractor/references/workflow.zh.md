# 工作流 —— 完整流程

> **说明：本文件为 `workflow.md` 的中文参考译本，供人阅读理解。skill 实际执行以英文原版为准。**

本文件展开 SKILL.md 中的五个步骤。会话中首次处理批次时阅读。

## 目录

1. 解析目录
2. 识别页码并定位章节
3. 提取标注文字与可视化对象
4. 处理跨页残缺与拼接
5. 输出

## 步骤一 —— 解析目录

仅当用户上传目录（目录/目次）图片时触发。

1. 识别每个标题、其层级（部 / 章 / 节）及起始页码。
2. 保留原标题文字——不要改写。
3. 生成反映层级的 Markdown 大纲。
4. 推断页码范围：
   - 章节起始 = 所列页码；
   - 章节结束 =（下一个同级或更高层级标题的起始页）− 1；
   - 若无法判断结束页，标记「起始页以后，待后续目录确认」。
5. 输出：(a) 识别到的大纲，(b) 每章页码范围，(c) 单独的「待确认项」清单。

目录照片常见问题提示：页面弯曲与拍摄角度会使标签（如 附录A/附录B）与其标题在垂直方向错位。需对照书籍实际结构加以调和，并在识别说明中陈述该假设，邀请用户更正。

**页码范围一经推断即锁定为权威状态。** 后续批次不得悄悄重新推断——章节边界不得在批次间漂移。仅当目录更正或用户明确要求时才修订。

## 步骤二 —— 识别页码并定位章节

每批正文页：

1. 优先从页边、页眉、页脚、角落寻找页码。**上传的照片可能乱序**——始终先读出真实页码，按它处理/排序，而非按上传位置。
2. 页码可能是阿拉伯数字、罗马数字、中文数字或小号印刷体。
3. 若一张图同时含左右两页，分别识别并处理各自页码。
4. 将每页页码与锁定的目录范围比对，定位最具体的章节或小节。
5. **严格按页码落章。** 某条提取归入"其页码落在该锁定范围内"的章节——绝不因同张照片里相邻页属于某章就把它塞进去。若一页横跨两章，根据标题、页码位置与正文内容分别归类。
6. **冲突检查：** 若某条提取的页码落在你打算归入章节的范围之外，重读页码；若仍冲突，按页码归类（范围为权威），并在识别说明中标注。不要把某页硬塞进范围并不包含它的章节。
7. 若页码无法识别：尝试从页眉、章节标题、上下文推断；仍无法判断则归入「待确认章节」。

## 步骤三 —— 提取标注文字与可视化对象

标注形式包括但不限于：
1. 被手画括号框住的文字：`【】`、`[]`、`〔〕`、`()`、`（）`；
2. 底部有直线、波浪线或双线的文字；
3. 被高亮笔、色块或荧光笔覆盖的文字；
4. 段落侧边有竖线、括线、圈画或箭头的段落；
5. 手写符号明显指向的正文；
6. 被邻近/接触的星号、箭头、对勾、圈、括号、侧边竖线或其他对象级符号选中的可视化对象；
7. “全部图表”显式或会话持续范围生效时，已提供照片上的每个可视化对象。

**标注括号 vs. 印刷括号（关键——最高频人工返工点）：**
- 读者*手画*在一段文字外围的括号是"标记"。输出框内文字、**不带**括号符号——括号绝不出现在输出里。
- 属于排版文字一部分的*印刷括号*（简短的行内注释/音译/引证/插注，如 `（Iwan）`、`（heuristics）`、`（约50万人）`）是"内容"，原样保留。
- 如何区分：手画标记大而不规则、框住整个分句/句子/段落、常贴近行缘；印刷括号小而规整、排版印刷、位于句内、围绕简短注释。当括号明显框住整段被标内容时，剥离它。

提取规则（逐字、纯文本）：
1. 保留原文——不总结、不改写、不润色——且不加任何自己的加粗/斜体/强调。输出为纯文本；唯一添加的标记是页码上标和存疑标注。
2. OCR 时保留原始标点、专有名词、数字、英文大小写。
3. 标注覆盖完整句子 → 提取完整句子。
4. 标注跨多行但语义连续 → 合并为一条引述。
5. 侧边竖线覆盖一个或多个段落 → 提取对应的完整段落。
6. **部分标注 → 吸附到句界。** 优先提取被标跨度所属的完整句子，而非残缺碎片。不要输出半截句子或用省略号拼接的 `……（碎片）`。若被标跨度确实是干净的子句，按可读单元提取该子句（可补必要标点）；绝不留下断在词语中间的碎片。
7. 不要提取未标注的普通正文。
8. 不要把页眉、页脚、脚注编号、页码误认为标注。
9. 应用用户明确提出的“全部图表”范围后，某页仍无被选文字或图表 → 仅返回：`该页未发现标注内容。`（或源语言对应说法）。

### 可视化对象

当标记明确选中表格、矩阵、统计图、流程图、地图、时间轴、截图、插图等对象时，提取整个对象，而不是只提取离标记最近的几个标签。剥离读者的选择符号。用户明确要求“全部图表”时，每张已提供照片里的每个图表都被选中，同页多个对象也不例外。若用户声明上传照片就代表其中图表均要提取，该规则在当前书籍会话持续生效。

将以下内容组成一个“图表语义单元”：

- 图表本体及其显式结构；
- 图号/表号、标题或图注、图例、坐标轴、单位、来源、图表专属脚注和印刷标注线；
- 只收录最少量、直接介绍或解码图表的邻近完整句子，并置于“关联说明：”下。

不得因为位置相近就收录普通邻近正文。逐项定义图表术语或继续展开作者论述的一组段落，即使主题相关，也属于普通正文；只有被独立标注时才提取。若图表块后还有独立标注正文，先放置“其他独立标注：”，避免与关联说明混淆。呈现路由、文字优先降级、忠实性规则与三道质量门见 `visual-extraction.md`（中文参考 `visual-extraction.zh.md`）；生成围栏 SVG 前阅读 `svg-reconstruction.md`（中文参考 `svg-reconstruction.zh.md`）。

## 步骤四 —— 跨页残缺与拼接

标注或被选图表可能在页边界被切断。常见情况：
1. 页首只有闭合符号 `]` `】` `)` `）`；
2. 页尾只有开启符号 `[` `【` `(` `（`；
3. 下划线 / 高亮 / 竖线从上一页延续到下一页；
4. 句子在页末中断、下一页继续；
5. 同一段标注被分页切断；
6. 表格、流程图、图例、图注或其他图表单元延续到相邻页。

处理规则：
1. 若当前页开头明显承接上一页未完成的标注，与暂存片段合并。
2. 若当前页结尾出现未完成标注，暂存为「待拼接片段」，等待下一页。
3. 若必须即时输出，标记为：
   ```
   > [待续] 当前页识别到的残缺标注文本……
   ```
4. 下一页补全后，输出合并后的完整内容并说明：
   ```
   已与上一页残缺标注合并。
   ```
5. 拼接只恢复原始连续性——绝不扩写或编造文字、单元格、连线、箭头、标签或数据。
6. 若无法判断如何拼接，保留原样并标记：
   ```
   > [疑似残缺，待确认] ……
   ```
7. **绝不静默输出截断的提取。** 一个无 `[页底截断]` / `[待续]` 标记、断在句中的引用块就是 bug。每次截断都用同样方式标记。
8. 跨页图表在各部分到齐前保持待续；必须即时输出时标记 `[图表局部截断，待续]`，并说明缺失方向。

**每批结束前的覆盖核对**（防整对象漏提）：
- 本批识别到的每个页码都已交代（产出提取、或注明无标注）；
- 任何从页底跑出的开启括号/下划线/竖线都有对应的待拼接片段；
- 每个对象级标记都有目标，每个被选图表都有必要附属信息，或已说明缺失原因；
- 每个被裁断或跨页图表都有对应待续记录；
- 连续页码段中无跳页；若已覆盖页码存在缺口，在识别说明里上报。

## 步骤五 —— 输出（另见 output-templates.md）

每批默认：只输出本批次的新增提取，按章节分组，每个引用块末尾带上标页码，为纯文本（不加粗/强调）。

被选图表使用图号/标题加信息损失最小的结构化呈现。默认生成包含结构化转录及必要 `svg` 围栏的单一 Markdown 文件，兼容 Obsidian SVG Editor，并使用规定的固定画布与明确前景色；不含截图、图片链接或 Base64。只有用户明确要求证据模式时，才为每个对象保存并嵌入一张裁图。直接关联说明放在独立标签下。使用 `output-templates.md` 中的图表模板，不得输出无对应文件的占位图片链接。

**每章内按页码升序排列**，即便照片乱序到达；章节按目录排序。

一批含多个章节 → 按目录顺序分章节标题输出。

页码/章节不确定：
```
### 待确认章节（疑似第X页）

> [章节待确认] 标注内容……
```

OCR 字词不确定：
```
> 原文前半部分〔疑似：某词〕原文后半部分。
```

不要用自己的话解释标注内容。图表转录可使用中性结构标签，但不得解释作者观点。识别说明只用于说明页码、章节、OCR 或图表识别的不确定性。交付前运行 `scripts/validate_visual_markdown.py`，再检查 Obsidian 实时预览/阅读视图中的 SVG Editor 渲染，并与源照片做目视对照。
