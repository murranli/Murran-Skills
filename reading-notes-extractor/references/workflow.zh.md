# 工作流 —— 完整流程

> **说明：本文件为 `workflow.md` 的中文参考译本，供人阅读理解。skill 实际执行以英文原版为准。**

本文件展开 SKILL.md 中的五个步骤。会话中首次处理批次时阅读。

## 步骤一 —— 解析目录

仅当用户上传目录（目录/目次）图片时触发。

1. 识别每个标题、其层级（部 / 章 / 节）及起始页码。
2. 保留原标题文字——不要改写。
3. 生成反映层级的 Markdown 大纲。
4. 推断页码范围：
   - 章节起始 = 所列页码；
   - 章节结束 =（下一个同级或更高层级标题的起始页）− 1；
   - 若无法判断结束页，标记「起始页以后，待后续目录确认」。
5. 输出：(a) 识别到的大纲，(b) 每章页码范围，(c) 单独的「待确认项」清单，列出任何不确定的标题或页码。

大纲格式示例：

```
# 书名或读书笔记标题

## 第一章 章节名称（第1-20页）

### 第一节 小节名称（第3-8页）

### 第二节 小节名称（第9-20页）
```

目录照片常见问题提示：页面弯曲与拍摄角度会使标签（如 附录A/附录B）与其标题在垂直方向错位。需对照书籍实际结构加以调和，并在识别说明中陈述该假设，邀请用户更正。

## 步骤二 —— 识别页码并定位章节

每批正文页：

1. 优先从页边、页眉、页脚、角落寻找页码。
2. 页码可能是阿拉伯数字、罗马数字、中文数字或小号印刷体。
3. 若一张图同时含左右两页，分别识别并处理各自页码。
4. 将识别到的页码与目录范围比对，定位最具体的章节或小节。
5. 若一页横跨两章，根据标题、页码位置与正文内容，分别归类到对应章节。
6. 若页码无法识别：尝试从页眉、章节标题、上下文推断；仍无法判断则归入「待确认章节」。

## 步骤三 —— 提取标注内容

标注形式包括但不限于：
1. 被中括号类符号包围：`【】`、`[]`、`〔〕`；
2. 被小括号 `()`、`（）` 包围、且明显属于读书标注（而非作者本身的括注——结合上下文判断）的文本；
3. 底部有直线、波浪线或双线的文本；
4. 被高亮笔、色块或荧光笔覆盖的文本；
5. 段落侧边有竖线、括线、圈画或箭头的段落；
6. 手写符号明显指向的正文。

提取规则（逐字）：
1. 保留原文——不总结、不改写、不润色。
2. OCR 时保留原始标点、专有名词、数字、英文大小写。
3. 标注覆盖完整句子 → 提取完整句子。
4. 标注跨多行但语义连续 → 合并为一条引述。
5. 侧边竖线覆盖一个或多个段落 → 提取对应的完整段落。
6. 仅标注句子的一部分 → 只提取被标注部分；可补入必要标点以保持可读。
7. 不要提取未标注的普通正文。
8. 不要把页眉、页脚、脚注编号、页码误认为标注。
9. 某页无标注 → 仅返回：`该页未发现标注内容。`（或源语言对应说法）。

## 步骤四 —— 跨页残缺与拼接

标注可能在页边界被切断。常见情况：
1. 页首只有闭合符号 `]` `】` `)` `）`；
2. 页尾只有开启符号 `[` `【` `(` `（`；
3. 下划线 / 高亮 / 竖线从上一页延续到下一页；
4. 句子在页末中断、下一页继续；
5. 同一段标注被分页切断。

处理规则：
1. 若当前页开头明显承接上一页未完成的标注，与暂存片段合并。
2. 若当前页结尾出现未完成标注，暂存为「待拼接片段」，等待下一页。
3. 若必须即时输出，标记为：
   ```
   > [待续] 当前页识别到的残缺标注文本……
   ```
4. 下一页补全后，输出合并后的完整内容并说明：
   ```
   已与上一页残缺标注合并。
   ```
5. 拼接仅用于恢复原文连续性——绝不扩写或编造文字。
6. 若无法判断如何拼接，保留原样并标记：
   ```
   > [疑似残缺，待确认] ……
   ```

## 步骤五 —— 输出（另见 output-templates.md）

每批默认：只输出本批次的新增提取，按章节分组，每个引用块末尾带上标页码。

一批含多个章节 → 按顺序分章节标题输出。

页码/章节不确定：
```
### 待确认章节（疑似第X页）

> [章节待确认] 标注内容……
```

OCR 字词不确定：
```
> 原文前半部分〔疑似：某词〕原文后半部分。
```

不要用自己的话解释标注内容，除非是在识别说明块中说明页码/章节/OCR 不确定性。
