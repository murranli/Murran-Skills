# Changelog — reading-notes-extractor

本文件记录 skill 的版本变更历史。版本号为本仓库内部约定（非语义化版本严格定义），以「主要规则是否变化」为升级依据。日期为对应迭代发生的会话日期，可能为近似值。

## v1.2.0 — 2026-08（第三次迭代）

在原文标注提取能力上，正式增加书籍照片中图表类可视化对象的忠实识别、结构化转录与代码化还原：

- **对象级选择与会话范围**：星号、箭头、圈画等明确指向整张图表时选中整个对象；用户声明“全部图表”或“上传照片即代表提取图表”后，该范围在当前书籍会话持续生效，同页多个对象均不遗漏。
- **图表语义单元**：图表本体、图号/标题、图例、坐标轴、单位、来源、专属脚注/标注线与最少量直接说明保持为一个完整单元；普通邻近正文和独立标注严格分隔。
- **单文件默认交付**：默认不保存截图、图片链接或 Base64；使用兼容性 Markdown 表格、可搜索结构化转录，以及在可靠时由 Obsidian SVG Editor 渲染的 `svg` 围栏。裁图仅作为用户明确要求的可选证据。
- **分类型呈现与克制降级**：表格、统计图、象限、分层/放射/架构、流程、公式、照片/广告及地图分别选择信息损失最小的形式；拓扑不清时退回结构化文字，不生成貌似合理但未经证据支持的图形。
- **SVG 固定画布与可读性**：每个 SVG 首层使用 `#F5F7FA` 100% 填充、`#000000` 8% 描边的完整背景，内部使用明确深色前景；在 Obsidian 实时预览、阅读视图及应用明暗主题下保持可读。
- **几何校准**：连接线止于节点边界并留小间隙；分层/伪三维图复用共边、统一投影并将分隔线裁剪在所属平面内，避免线条穿入节点或装饰线错位。
- **自动校验**：新增几何辅助与 Markdown/SVG 校验脚本，检查表格连续性、`svg` 围栏、固定画布、外部资源、连接端点和平面分隔线，并保留源照片目视对照门槛。

本轮内部曾依次尝试“双裁图 → 单裁图 → 裸行内 SVG 与主题继承色”；前两者因资源冗余与检索不便被放弃，裸 SVG 因 Obsidian 阅读视图兼容性不足被放弃，最终收敛为“结构化转录 + SVG Editor 围栏 + 固定浅色画布”。

新增：`references/visual-extraction.md`、`references/svg-reconstruction.md`、`scripts/svg_geometry.py`、`scripts/validate_visual_markdown.py` 及中英文对应文档；同步更新主 skill、工作流、输出模板与 README。

## v1.1.0 — 2026-06（第二次迭代）

基于一次真实使用（《看不见的中东》整本提取）后的人工修正版对比，识别并修复 7 处问题：

- **剥离标注括号**：区分「读者手画的标注括号」（剥离、不出现在输出）与「书籍印刷自带的括号」如 `（Iwan）`（保留为内容）。此前一律保留，是最高频的人工返工点。
- **锁定页码范围**：目录解析后将章节页码范围固定为会话权威状态，后续批次不得重新推断，避免章节边界在批次间漂移。
- **按页码严格落章 + 冲突检查**：提取归属由其自身页码决定，页码落在范围外时报警而非硬塞。修复了「页码 172 被误归入 179–192 章节」类错误。
- **纯文本、去除越界加粗**：输出不再添加原文没有的 `**加粗**`/强调，唯一允许添加的是页码上标与存疑标注。
- **按页码正序排列**：上传照片可能乱序；读出真实页码后在每章内按页码升序排列，章节按目录排序。
- **截断必标记 + 覆盖核对**：跑出页缘的提取必须带 `[页底截断]`/`[待续]`，不得静默输出半句；每批结束做页码覆盖核对，防整段（尤其跨页括号）漏提。
- **OCR 易混字标注**：对 入/人、己/已、末/未、戊/戌/戍、重复字等常见混淆做自检，低置信处用 `〔疑似：x〕` 标注。

同步更新：`SKILL.md`、`references/workflow.md`、`references/output-templates.md` 及三份对应中文译本（`*.zh.md`）。

## v1.0.0 — 2026-06（首个版本）

将「书页图片 → 提取人工标注 → 按目录归类 → 输出 Markdown 读书笔记」的工作流首次沉淀为 skill。

- 五步工作流：解析目录、识别页码定位章节、提取标注、跨页拼接、Markdown 输出。
- 已校准的呈现格式：同章节合并、每条末尾用 Unicode 上标标页码、阶段性完整文件带「待提取」占位。
- 非简体中文先确认记录方式（保持原文 / 转简体）再提取。
- 三层文件结构：`SKILL.md` + `references/workflow.md` + `references/output-templates.md`，并各附中文参考译本。
