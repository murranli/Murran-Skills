# Changelog — reading-notes-extractor

本文件记录 skill 的版本变更历史。版本号为本仓库内部约定（非语义化版本严格定义），以「主要规则是否变化」为升级依据。日期为对应迭代发生的会话日期，可能为近似值。

## v1.1.0 — 2026-06（第二次迭代）

基于一次真实使用（《看不见的中东》整本提取）后的人工修正版对比，识别并修复 7 处问题：

- **剥离标注括号**：区分「读者手画的标注括号」（剥离、不出现在输出）与「书籍印刷自带的括号」如 `（Iwan）`（保留为内容）。此前一律保留，是最高频的人工返工点。
- **锁定页码范围**：目录解析后将章节页码范围固定为会话权威状态，后续批次不得重新推断，避免章节边界在批次间漂移。
- **按页码严格落章 + 冲突检查**：提取归属由其自身页码决定，页码落在范围外时报警而非硬塞。修复了「页码 172 被误归入 179–192 章节」类错误。
- **纯文本、去除越界加粗**：输出不再添加原文没有的 `**加粗**`/强调，唯一允许添加的是页码上标与存疑标注。
- **按页码正序排列**：上传照片可能乱序；读出真实页码后在每章内按页码升序排列，章节按目录排序。
- **截断必标记 + 覆盖核对**：跑出页缘的提取必须带 `[页底截断]`/`[待续]`，不得静默输出半句；每批结束做页码覆盖核对，防整段（尤其跨页括号）漏提。
- **OCR 易混字标注**：对 入/人、己/已、末/未、戊/戌/戍、重复字等常见混淆做自检，低置信处用 `〔疑似：x〕` 标注。

同步更新：`SKILL.md`、`references/workflow.md`、`references/output-templates.md` 及三份对应中文译本（`*.zh.md`）。

## v1.0.0 — 2026-06（首个版本）

将「书页图片 → 提取人工标注 → 按目录归类 → 输出 Markdown 读书笔记」的工作流首次沉淀为 skill。

- 五步工作流：解析目录、识别页码定位章节、提取标注、跨页拼接、Markdown 输出。
- 已校准的呈现格式：同章节合并、每条末尾用 Unicode 上标标页码、阶段性完整文件带「待提取」占位。
- 非简体中文先确认记录方式（保持原文 / 转简体）再提取。
- 三层文件结构：`SKILL.md` + `references/workflow.md` + `references/output-templates.md`，并各附中文参考译本。
